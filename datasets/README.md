# SmartFreight-AI Datasets

This directory stores the data used for training, evaluating, and validating SmartFreight-AI machine learning models.

## Folder Structure

- `raw/` — Original, unmodified source datasets (CSV, Excel, Parquet, JSON). Never edit files here directly.
- `processed/` — Cleaned, transformed, and feature-engineered datasets generated by preprocessing scripts.

## Git Tracking Rules

- Large data files (`*.csv`, `*.parquet`, `*.xlsx`, `*.zip`) and contents inside `raw/` and `processed/` are ignored by `.gitignore` so the repository stays lightweight.
- Keep `.gitkeep` files so the folder structure remains version-controlled.
- Document dataset sources, column schemas, and preprocessing notes here as datasets are added.
